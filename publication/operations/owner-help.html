Operations quick start

  1. Choose a site in the Notification Center or Project Map by its readable site name.
  2. Choose a site on the Project Map to reveal its reviewed notifications below the map, then open the separate Daily Progress page for reported work. A notice is not automatically outstanding.
  3. Correct facts in the owning Google Sheet. Use the repository for code, tests and publication history.
  4. Check the next Actions run, the separate Sources & History page, and the live site. Open documents through the Resource Library, where Drive controls access.

Historical Workspace and Guide development notes

Open your project map first

Use the project map as your daily workspace. Installation and startup settings are chosen on each device.

  • Windows: open this site in Microsoft Edge and install it as an app from the Apps menu. At edge://apps, enable Auto-start on device login for the installed map. It opens after you sign in.
  • Android: open the map in Chrome and use its menu to create a Home Screen shortcut.
  • iPhone: open the map in Safari, tap Share, then Add to Home Screen. Enable Open as Web App when offered.

A phone shortcut opens the map when tapped; it does not replace the phone wallpaper. A Windows webpage wallpaper needs a separate wallpaper application.

Map colours identify the public executing organization: blue for Fishtail Builders and orange for Rohini Engineering and Builders. Status is shown separately. Source facts remain in the original Google Sheets; native Google Doc notes need reviewed Sheet admission before publication. Reopen or refresh the map after a successful publication to see its latest snapshot.

Device instructions: Microsoft Edge apps, Windows auto-start, Chrome web apps, iPhone Home Screen.
